## 4. 已知限制与顺延项（不阻断发布）

1. **Release 页待补**：需为 PAT 增加 `Contents: read/write`，或换 token / 网页手动创建；notes 见下节。
2. **迁移窗口**：旧 `quest-panel` / `CastleQuestPlugin` / `quest.*` 事件本版保留，以守住 V0.5 基线回归；V0.6 移除并重截世界主视图。
3. **O-1**：顶栏 9.681% 视觉差异源自 V0.5 既存 Google Fonts 外链字形（D-1）+ 采集时 `helpOpen` 状态差异，非 V0.51 引入；canonical 保留不静默替换，留 V0.6 独立 DDR。
4. **性能**：软件渲染下 329 draw calls 导致绝对帧率偏低，是 V0.5 既有问题（AC-122 已归因）；V0.6 合批候选不变。绝对 FPS 跨会话漂移（21.2 → 16.5），判定按 D-2 用同机同脚本配对对照。
5. **内容偏差**：侧栏标题「任务 · 城堡水务」（已含跨主题任务）、首个高亮任务 `mission.moat.v1`（为保持 V0.5 顺序契约）、`life-simulation` 表达形式留 V0.6（AC-231 阈值 ≥3，本版 5 种）。
6. **A/B 流程**：GATE-2 的 B `FULLY SATISFIED` 已满足「B 满意后提交 owner」；GATE-2 之后新增内容由验收报告与发布前 47 E2E 全量复核覆盖，未再召唤 B 做终验。如需补做可另行安排。
7. **Q-4**：Master Plan V2.0 原文仍缺，文案按 V0.2 产品文档与学习规格撰写，owner 可润色点列入 V0.6。
