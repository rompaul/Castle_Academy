# V0.6.1 Release Notes

**状态：** **已定稿**（STOP GATE-3 ACCEPT，2026-11-14）；版本号 `0.6.1` / tag `v0.6.1`
**基线：** tag `v0.6.0` / `0bd6e4f`（V0.6 正式发布对象）
**性质：** 功能增量版（与 V0.51 同语义），不是 hotfix；独立 tag / 独立 canonical 集 / 独立性能报告

## 一句话

V0.6.1 给城堡加入了「电」的规则玩法，并首次让 V0.6 的知识与任务层被真实消费；同时把方块栏改成 9 格快捷栏 + 分类浏览，更好用、也更好找方块。

## 新增内容

- **9 个电力 / 水联动方块**：电源、电线、开关（断开 / 合上）、灯、信标、水泵、阀门（开 / 闭）。只追加 ID，既有 25 个方块 ID 与顺序零变更。
- **电力规则**：六正交邻接、二值通断、多源冲突、开关断开诊断；通电 / 断电是**派生态**，不写回世界存档；导线逐段点亮的 overlay，不烘焙第二套纹理（atlas 实测 49/64）。
- **开关像生活里的开关**：注视开关按 `F` 合上 / 断开，左键放方块、右键拆方块照旧；学习证据要求**同一个位置**的「合上（灯亮）+ 断开（灯灭）」成对观察。
- **水电联动**：通电的水泵经窄端口成为虚拟水源，水侧传播仍由水插件独占。
- **学习任务**：3 个按 V0.6 schema v2 写的电力任务、A→B 先决链、5 个新知识点（`kp.electric.*`）、3 个确定性评估器、3 级提示阶梯；6–7 档活动 C 拆成 C1 / C2 单系统子路径。
- **儿童安全**：统一用「电」命名，禁用红石类识别性术语与真实电气操作词；首次引导、帮助面板常驻、家长 / 教师说明三条安全文案。
- **MC 式方块栏（DDR-0002）**：9 格快捷栏 + 「所有方块」分类面板（7 类，电力 9 块按 E1 四组）；`E` 打开、数字键 `1–9` / 滚轮切格，点方块放进当前格；默认 9 格仍是原来的前 9 个方块。

## 已知限制

- 软件渲染（SwiftShader）下约 21.8fps，属既有环境瓶颈（AC-122 已归因），并非产品设备性能回退。
- GitHub Release 页需 owner 手动创建：fine-grained PAT 无 release 写权限（403，与 v0.5.0 / v0.6.0 同因）。
- 迁移窗口保留旧 `quest-panel` / `quest.*` 事件与 15 个旧任务 ID，避免破坏 V0.5 基线；清理顺延到 V0.6.1 之后。
- O-1：顶栏 / footer 外链字体导致的既有像素噪声，保留 canonical，留独立 DDR。
- `npm run verify:source` 仍 exit 1（DEV-601，`scripts/v05-quest-screenshots.mjs` import `playwright` 未声明，脚本未被引用）——既有缺陷，只读登记未修，不阻塞本版。
- 工程模拟（水压 / 流速 / 泵曲线）归 V0.7 Experiment 方向（Q-6 跨版本 OPEN）。
