## 1. Release objective

Deliver V0.4 "Underground infrastructure" per the Product Master Plan roadmap (`00_Product_Master_Plan/README.md:57`): negative Y support, layer organization, and section view for inspecting underground/above-ground structure.

## 2. Delivered

### V04-014 — LayerRenderAdapter (new)
- `src/rendering/LayerRenderAdapter.ts` — maps `layerId` → Three.js `Group`; `addMeshToLayer`/`removeMeshFromLayer`/`setLayerVisible`/`applyLayerVisibility`/`applyAllLayerVisibility`/`removeAllGroups`.

### V04-013 — LayerPlugin facade (new)
- `src/plugins/layers/LayerPlugin.ts` — facade over `LayerRegistry` + `EventBus`; layer register/query/visibility/view-mode; emits `layer.visibility.changed`, `view.mode.changed`, `layer.active.changed`.

### V04-015 — LayerRenderAdapter 接入 ThreeWorldRenderer
- `src/rendering/ThreeWorldRenderer.ts` — constructor accepts optional `LayerPlugin`/`LayerRenderAdapter`; `addBlock`/`removeBlock`/`reloadFromWorld` route meshes through `LayerRenderAdapter` with `mesh.userData.layerId`; raycast filters hidden layers; `dispose` cleans up.
- `src/plugins/layers/LayerPlugin.ts` — added `isLayerEffectivelyVisible`.

### V04-016 — 图层面板 UI
- `src/rendering/GameCanvas.tsx` — `GameActions` exposes `layerPlugin`.
- `src/app/App.tsx` — Layers panel: view mode (all/above-ground/underground/current-layer), active layer, per-layer visibility checkboxes with Y range and buildable tag.
- `src/ui/styles.css` — `.layer-panel`, `.layer-section`, `.layer-row`, `.layer-tag` styles.

### V04-017 — 剖面 UI
- `src/plugins/layers/LayerTypes.ts` — `LayerState` gains `section: SectionViewState`; `SectionAxis` extended to `"x" | "y" | "z"`.
- `src/plugins/layers/LayerPlugin.ts` — `getSectionView`/`setSectionView`/`onSectionChange`; emits `section.view.changed`.
- `src/rendering/ThreeWorldRenderer.ts` — subscribes `section.view.changed`; `applySectionView`/`applySectionViewSingle` control per-mesh `mesh.visible` by axis/coordinate/keptSide; `addBlock`/`reloadFromWorld` apply section; outline/target cleared when hidden.
- `src/app/App.tsx` — Section controls in Layers panel: Enabled, Axis X/Y/Z, coordinate input, Keep +/-.

### V04-018 — 图标式图层面板重构
- `src/app/App.tsx` — Layers: Ground (Home) / Underground (ArrowDown) icon buttons; Section: Axis X/Y/Z (ArrowRight/ArrowUp/ArrowLeft) icon buttons.
- `src/ui/styles.css` — `.layer-icons`/`.layer-icon` active-state styles.

### V04-019 — Ground/Underground 可同时选中
- `src/app/App.tsx` — Layers: two independent checkboxes (Ground controls `minY >= 0` layers; Underground controls `maxYExclusive <= 0` layers); both can be selected simultaneously. `onViewModeChange`/`onSectionChange` subscription drives React state so icon active states refresh on click.
- Removed `ViewMode` select and per-layer visibility list (replaced by icon model).

## 5. Remaining defects / risks

- E2E persistence cross-reload failure (Load button not enabled): pre-existing V0.3 defect, not V0.4.
- Layer/section view state is **not persisted** in V0.2 world snapshot (view-only). Cross-session preferences require future persistence extension.
- Default layers cover Y [-4, 8); blocks outside this range fall back to default layer. More layer definitions may be needed for deeper underground (down to Y -32).
- `PlayerController.tryMoveVertical` still clamps Y to `[PLAYER_EYE_HEIGHT, 24]` — player cannot descend below ground. Recorded as V0.4 risk in COORDINATE_CALLSITE_AUDIT; deferred to a later task.
- `ThreeWorldRenderer.adjacentPosition` on ground click hard-returns `y=0` — cannot place on underground surface. Deferred to a later task.
