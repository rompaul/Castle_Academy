## 1. Release objective

Deliver V0.3 "Building tools, blueprints, and measurement challenges" per the Product Master Plan roadmap
(`00_Product_Master_Plan/README.md:55-56`): higher-order block operations, reusable blueprint templates,
and measurement challenges supporting the "Learn Through Building" philosophy.

## 2. Delivered

- **BuildingToolsPlugin** (`src/plugins/building-tools/BuildingToolsPlugin.ts`):
  - Line placement between two 3D grid positions (inclusive)
  - Solid rectangle/cuboid fill (any corner order)
  - Region copy to clipboard (normalized relative to min corner)
  - Region paste at origin (does not overwrite existing blocks)
  - Tool selection (place/line/fill/copy/paste) + clipboard clear
  - Events: `world.block.placed`, `world.building-tools.line-placed`,
    `world.building-tools.rectangle-filled`, `world.building-tools.region-copied`,
    `world.building-tools.region-pasted`, `world.building-tools.clipboard-cleared`

- **BlueprintPlugin** (`src/plugins/blueprint/BlueprintPlugin.ts`):
  - Save/load/list/delete blueprints (name → blocks snapshot)
  - Blocks normalized relative to min corner for translation-invariant placement
  - Place blueprint at origin without overwriting existing blocks
  - Event: `world.blueprint.saved`, `world.blueprint.deleted`, `world.blueprint.placed`
  - Blueprint data: coordinates + block IDs only, no personal data (`CA-TECH-005:9-11`)

- **MeasurementPlugin** (`src/plugins/measurement/MeasurementPlugin.ts`):
  - Euclidean distance, XZ-plane area, cuboid volume measurements
  - Challenge target + tolerance, pass/fail check with message
  - Pure calculations, no world-state mutation

- **EventBus export** (`src/core/events/EventBus.ts`): `DomainEvent<T>` interface exported
  for type-safe event payloads (fixes unsafe `any`/`as` casts in tests, `CA-TECH-002:14-16`)

- **Shell wiring** (`src/rendering/GameCanvas.tsx`, `src/app/App.tsx`):
  - Instantiates and activates all three plugins, wires into `gameRef`
  - UI: tool selector dropdown, blueprint save/place controls, measurement challenge input,
    result hint; version badge and footer updated to V0.3

- **Tests**: 21 new unit tests (BuildingTools 9, Blueprint 10, Measurement 11); 49 total passing
- **ADR-0003** (`docs/ADR-0003-V0.3-Building-Tools-Blueprints-Measurement.md`): architecture decision recorded
