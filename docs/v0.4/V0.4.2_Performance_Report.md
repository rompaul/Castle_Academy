# V042-010 — 渲染性能报告（纹理 vs 纯色基线）

**日期：** 2026-11-07
**环境：** Windows 11，Chromium（Playwright headless），1280×720，Vite dev server（DEV 模式）
**方法：** `scripts/v042-perf.mjs`。两种模式各采 300 帧：
- `?flat=1`：DEV-only 开关跳过程序化纹理，纯色材质（等价 V0.4.1 渲染路径）
- 默认：V0.4.2 程序化纹理（每块 top/side/bottom 三面 CanvasTexture，NearestFilter）

## 结果

| 指标 | 纯色基线 | 纹理模式（run 1） | 纹理模式（run 2） |
|---|---|---|---|
| 平均 FPS | 54.4 | 47.6 | 47.3 |
| 平均帧时间 | 18.39 ms | 21.01 ms | 21.15 ms |
| P95 帧时间 | 33.4 ms | 33.4 ms | 33.4 ms |
| Draw calls | 67 | 392 | 392 |
| 三角形 | 792 | 792 | 792 |
| 显存纹理数 | 1 | 7 | 7 |

## 分析

- 帧时间增加约 **+14%**（18.4 → 21.0 ms），可接受；P95 相同（33.4 ms，受帧调度上限影响）。
- **Draw calls 67 → 392（约 5.9 倍）是主要开销**：每个带纹理方块使用 6 材质数组（side/top/bottom/side/top/side），Three.js 对多材质网格按组提交。
- 显存纹理数仅计当前场景实际使用面（种子世界使用 grass/wood/stone 等 7 个块）；全 22 块注册表懒加载，未用块不产生纹理上传。
