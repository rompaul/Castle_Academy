## 3. M1~M8 逐图对照

判定口径（沿用 `V07_Mission_Form_Board.md` §6）：结构、层级、配色、文案逐项核对；允许布局微调，不允许功能越界；出现「分享 / 评分 / 等级 / 物理量」一律 `NOT SATISFIED`。

### M1 六类等权总览 → S2 + S3 + S11 + S12
- **结构一致**：六个形式各自一条任务、共享同一 `MissionDetailPanel` 层级（背景 → 目标 → 进度 → 形式专属区 → 3 级提示 → 说一说 → 出口）。
- **差异（可接受）**：参考图 M1 是一张独立的「六种表达形式」看板；实现**没有新增独立页面 / dashboard**，按 `V07_Screen_Inventory.md` S3 的「若实现」口径，以侧栏末尾六条任务卡片代替。这是 `V07_Mission_Form_Board.md` §1 红线「不新增全屏模态或大 dashboard」的直接结果，须在角色 B 评审中作为**已登记差异**说明。
- **配色一致**：`--ca-teal-600` 标题栏、`--ca-surface-white` 卡片、`--ca-border-soft` 描边、选中态 `--ca-teal-100`。
- **文案一致**：无「难度阶梯」「等级」「年级」暗示；六类任务并列，没有主次排序说明。

### M2 观察清单 → S4 + S14
- **结构一致**：3 行位置清单 + 逐行「记下」按钮 + 计数「0/3 处」「3/3 处」。
- **文案差异（可接受）**：参考图写「走到亮起来的观察点」，实现改为直接点按钮「记下」（不引入 3D 观察点交互，本版不新增世界机制）；参考图「只看位置，不评内容」在实现里表达为「记下的是地方，不用写句子」。
- **红线核对**：无文字对错评分、不要求写句子、无百分比与星级；空态用中性灰蓝 `--ca-slate-600`，无警告色。

### M3 两态对照 → S5（重点）
- **结构一致**：同一位置成对状态并排；「合上 · 灯亮」「断开 · 灯不亮」各带文字标签，**不只靠颜色**。
- **差异（可接受）**：参考图是独立大卡 + 单独提示卡；实现压缩成详情面板内一行对照 +「记下这组对照」写入按钮。原因是 `V07-022` 之前的接线修复发现 `variableComparison` 通道缺产品写入方，按钮是必需的取证动作。
- **红线核对（重点）**：**未出现**水压 / 流速 / 电压 / 电流 / 泵曲线 / 任何数值单位；实现反而显式写「不提任何数值」。无分数、无等级、无对错、无分享按钮、无外链。安全文案「城堡里的电只玩通和断……不要碰插座和电线」在面板底部常驻。
- **过程说明**：`completionSuppressed` 修复后本任务会真正完成，首次截图被完成弹层盖住；脚本在取证前先关弹层并重开同一任务，最终图干净无遮挡。

### M4 假设切换 → S6
- **结构一致**：多猜想 chip + 当前假设 +「按这个猜想去查一次」验证出口。
- **文案差异（可接受）**：参考图「改了不扣分」在实现里统一为「改错猜想没关系 / 怎么改都没关系」，避免引入「扣分」这个反向评分词（V0.7 儿童文案口径）。
- **红线核对**：改猜想不惩罚、不锁死第一次选择、无答对/答错、无分数与星级；「再看看」类中性反馈保留。

### M5 情境决策 → S7
- **结构一致**：情境条件 + 分步决策 + 结果回看；实测可见「第 2 步 · 选一个做法」及 3 步回看清单、「回看上一步」。
- **差异（可接受）**：参考图是「第 1 步」初始态，实现截图捕获的是已选一步后的「第 2 步」态，用于证明可改选与回看；步骤数仍为 3。
- **红线核对**：无真实工程结论、不改 `WorldSnapshot v1` / 世界方块、无分数等级。

### M6 本地解释卡 → S8（重点）
- **结构一致**：本地解释卡 + 文字框 +「记下我的想法」按钮。
- **差异（可接受）**：参考图是独立卡「我的解释卡」；实现复用既有 `MissionDetailPanel` 的「写下你的设计说明」输入（`ca-evidence-input` 语义），符合 `V07_Mission_Form_Board.md` §2 Communication「复用」口径；空态文案「还没有留下解释，想写的时候再写」。
- **红线核对（重点）**：**未出现**「分享」「链接」「上传」「发给同学」「评分」「星级」「对错」任何按钮或外链；明确写「只在本机看」「不上传、不打分」。按钮旁「至少 12 个字；只检查长度，不评判内容」是长度校验提示，不评价内容。

### M7 反思输入 → S9 + S14（重点）
- **结构一致**：「说一说（可以不写）」+ 文本域 +「记下我的想法」/「跳过」等价能力（本版实现为「不写也没关系，不影响任务」，未写也能完成）。
- **文案一致**：「只在这次游戏里保留，读档、刷新或关掉就没了；不会保存、不会打分、不会上传。」
- **红线核对（重点）**：**未出现**分数、星级、等级、百分比、对错判定、强制填写提示；S14 证明反思为空时任务正常完成且提示保持中性。typing guard 由 `src/app/App.tsx` 覆盖输入框，`v07UiTokens.test.ts` 静态断言。

### M8 证据面板 → S10 + 附加 S14（重点）
- **结构一致**：本地证据面板只列计数与文本；既有「我的证据」只读面板列掌握证据句卡 + 任务名。
- **差异（可接受）**：参考图 M8 是句子化的「做了什么、观察到什么」长句；实现的本地面板是**计数清单**（3 条 / 0 条 / 2 条 / 还没写），句子化证据由既有 `EvidenceRecordPanel` 承担（附加截图）。两者合并覆盖 M8 语义。
- **红线核对（重点）**：**未出现**掌握度、百分比、等级、Tier、难度、年级、排名、星级。附加图中的「3/3」「2/2」是任务进度分子/分母（既有 `progressLanguage`），不是百分比或评级；面板明写「证据只记录你做过什么，不会打分，也不会上传。」
- **注**：附加图出现两次「开关让电停下」句卡，来自两个不同任务的追加写入；符合 `V07-010` 掌握证据链「只追加、不去重」的既有口径。
