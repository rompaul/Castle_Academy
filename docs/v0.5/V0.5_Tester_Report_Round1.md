## 4. 发现清单（只记录，不修复；按优先级排列）

| # | 级别 | 发现 | 位置/证据 |

| F-3 | 中 · 规格缺口 | Scope Summary 用户可见成果第 7 条"提供水信息查看：选中/悬停水相关方块时显示简单状态（水源/有水/渠/管道通水）"**未实现**：指针悬停水源/渠/管道/水格时无任何状态说明（`updateRay`/`onPointerMove` 无消息发送）。对儿童玩家理解水状态有影响 | 全局搜索无对应实现；§2.4 UI 要求 |

| F-5 | 观察 · 环境 | 性能数据来自 SwiftShader 软渲染，不代表真实 GPU 表现；构建 chunk 692kB 警告为既有问题非 V0.5 新增 | `V0.5_Performance_Report.md`；build 输出 |

## 6. 测试者结论

### **SATISFIED**

理由：
1. AC-101~122 全部 22 条 Must-Pass 验收用例 **PASS（22/22）**，无 FAIL、无 BLOCKED、无 Not Run。
2. 单元测试 155/155、E2E 20/20、游戏内功能 24/24、生产构建与 preview 加载全部通过，全程 0 页面错误、0 控制台错误。

4. 无未关闭的 P0/P1 缺陷。

不满足项/需 owner 关注的清单（均不阻塞本轮验收，建议纳入修复清单或 V0.5.x）：
- **F-3（中）**：Scope Summary 第 7 条"水信息查看"未实现——建议补实现或由 owner 正式将其移出 V0.5 范围；
- **F-2（中）**：水井任务测量解锁未与判定耦合——与学习规格不一致，建议 owner 决定补做或改规格；
