## R2.0 环境说明（重要）

初轮游戏内验证出现 13 项中 7 项异常（含页面错误 `this.emitHoverInfo is not a function`）。排查确认**不是产品缺陷**：5173 端口上的 Vite dev server 自 Round 1 起持续运行，其 transform 缓存停留在修复过程中的**中间版本**（served 模块含 `emitHoverInfo` 调用点但缺方法定义，562 行 vs 磁盘 653 行）。重启 dev server（清除缓存）后异常全部消失。**测试结论以重启后的干净环境为准。**

另：welcome 覆盖层（`.welcome-card`，x∈[115,555]）会拦截其区域内的真实鼠标 pointermove——脚本改用 `canvas.dispatchEvent(PointerEvent)` 直发事件（与真实鼠标走同一 `onPointerMove` 处理器），未进入指针锁定（锁定时射线恒为屏幕中心，无法逐格悬停）。
